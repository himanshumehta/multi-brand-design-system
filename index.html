How a theme reaches a component

Four layers, each depending only on the one before it. Components never see a hex value.

  1. Contract63 token names in js/contract.js
  2. Themethemes/<id>.css assigns values, light and dark
  3. Semantic variables--color-primary, --surface-1, plus derived soft tints
  4. ComponentsButtons, forms, tables and slides read only those variables
