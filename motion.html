Motion

Three durations and three curves. Motion answers something the person did: a press, an open, a confirmation. Nothing on these pages animates on its own except loading states.

Durations

Fast for colour and hover changes, base for small movements, slow for panels and dialogs entering.

--duration-fast
--duration-base
--duration-slow

Easing

Slowed down here so the curves are visible. Standard for most transitions, emphasized for things entering the screen, spring for small confirmations like a switch thumb.

--ease-standard
--ease-emphasized
--ease-spring

In components

Try each control. The switch thumb uses spring, the toast and dialog use emphasized, the button press uses spring on transform.

Entering with emphasis

This dialog rises with --ease-emphasized over --duration-slow. The backdrop uses --overlay.

Reduced motion

When the system asks for reduced motion, every transition and animation collapses to 1 ms. State still changes; it just does not travel.

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 1ms !important;
    transition-duration: 1ms !important;
  }
}
