Token reference

The contract has 63 tokens. Every theme defines all of them; colour tokens are defined twice, once per mode. The values below are read from the page at runtime, so they change when you switch theme or mode.

Derived tokens

Soft tints are not part of the contract. css/catalogue.css mixes them from the contract colours, so a theme only has to supply the solid values.

--color-primary-soft: color-mix(in srgb, var(--color-primary) 13%, transparent);
--color-success-soft: color-mix(in srgb, var(--color-success) 14%, transparent);
/* also: secondary, accent, warning, danger, info */
