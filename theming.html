Theming

Themes are scoped by a data-theme attribute, not by :root. That means a theme can apply to the whole page or to one box inside it, which is how this page shows every theme and mode at once.

Every theme, both modes

The same markup, cloned into a scope per theme and mode. This grid is built from the theme registry, so a new theme appears here without editing this page.

How scoping works

A theme file sets the contract on an attribute selector. Dark mode is a second block that only overrides the colour group.

[data-theme="acme"] {
  --surface-0: #f6f7f9;
  --color-primary: #0a66c2;
  --font-display: "Your Display Face", sans-serif;
  /* …all 63 contract tokens */
}

[data-theme="acme"][data-mode="dark"] {
  --surface-0: #0d1117;
  --color-primary: #58a6ff;
  /* …colour tokens only */
}

Any element can opt into a theme. Nested scopes win over the page scope:

<section class="theme-scope" data-theme="acme" data-mode="dark">
  <button class="btn btn--primary">Rendered in Acme, dark</button>
</section>

Add a theme

  1. Copy a theme fileDuplicate themes/neutral.css as themes/acme.css and rename the selectors.
  2. Fill the contractChange values only. Keep every token name.
  3. Register itAdd an @import to themes/index.css and { id: "acme", label: "Acme" } to THEMES in js/theme-init.js.
  4. ValidateRun python3 sync-tokens.py; it fails if a token is missing.
